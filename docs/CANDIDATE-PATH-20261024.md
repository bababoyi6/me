## 高延迟入口：执行方案已准备，待本阶段授权

新增`lab_runner --profile candidate --rtt 100`，只在私有网络命名空间运行真实HAProxy、WireGuard+PSK、两个balanced2后端和单独的模拟DC。入口到后端设100ms RTT，后端采样必须实际观测到两端client TCP RTT超过5ms，覆盖应保留接收自动调节的条件；记录接收缓冲，不假称直接读取了内核user-lock位。

单次检查包括两个域名分别上传/下载256KiB，以及3次4KiB的主备切换/恢复探测；合成有效载荷共1,060,864字节，发送前强制不超过2MiB。两条隧道都记录纯数字收发计数，要求双向且至少覆盖对应有效载荷；不保存WireGuard私钥或公钥输出。实际核心版本、SHA256、路由、两后端RTT和DC错误均须通过，缺观测不能标成功。

该profile运行上限180秒、CPU60%，沿用原动态MemoryMax和宿主预留、Swap0、Tasks192及运行中OOM/磁盘/输出保护。75%软节流默认不变；使用80%须针对本阶段再次得到明确批准。结束后回收命名空间、服务、临时目录和密钥。
